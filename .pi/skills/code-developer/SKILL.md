# 💻 Skill: Code Developer

## Назначение
Написание и рефакторинг кода строго по ТЗ. Проверка только на этапе сборки (build) и запуска (start).

## Модель
Использует модель, указанную в frontmatter (по умолчанию gpt-4o). Пользователь может изменить её в конфиге.

## Scope (Что делает и что НЕТ)
✅ ДЕЛАЕТ:
- Пишет/изменяет код согласно плану из ТЗ.
- Запускает сборку (npm run build / docker compose build).
- Запускает проект (npm start / docker compose up).
- Исправляет ошибки компиляции/синтаксиса.

❌ НЕ ДЕЛАЕТ:
- Не проводит глубокое функциональное или интеграционное тестирование.
- Не проверяет UI/UX вручную (для этого есть image-viewer).

## Процесс работы
1. Получить задачу (файл из папки tasks/).
2. Реализовать код согласно разделу "План реализации".
3. Запустить сборку и убедиться, что нет ошибок.
4. Запустить проект и убедиться, что он стартует без крашей.
5. Вернуть краткий отчет: "Код написан, сборка ✅, запуск ✅".

## Интеграция
Вызывается субагентом task-solver делегированием задачи через /skill:code-developer.
